# Python Experiments
Python-Experiments is a suite consisting of small Python programs created as practice exercises; it is frequently updated with new mini-programs, and you are welcome to examine the code for each one.
# Projects
- Main: the main manager
- Chat-Yipiti: a multi-model interface that uses the ai.hackclub.com API, featuring models such as Claude, ChatGPT, Gemini, and Qwen
- Minirooms: a console line videogame
- Bast-Ultra-Mini: finance gestor
- Calc: a calculator
- inventario: a module of inventory for Product-CLI
- Product-Cli: Product Manager
- Programa-Ultra-Basico: a ultra basic program w a lil joke inside
- Fun Box: Just a funbox, w some practics (Not accessible from the main menu)
- Bank : Bank is a practice about classes (Not available in main menu)
# Run it locally
    git clone git clone https://github.com/YeremiSB/Python-Experiment
    cd project/src
    pip install -r requirements.txt
    python main.py
